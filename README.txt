פשוט להצליח במתמטיקה – אפליקציה לטלפון (PWA)
==============================================

איך מעלים לאוויר (5 דקות, חינם):
1. פותחים במחשב את https://app.netlify.com/drop  (צריך חשבון חינמי)
2. מחלצים את קובץ ה-ZIP לתיקייה, וגוררים את התיקייה כולה לחלון.
3. מקבלים כתובת (אפשר לשנות את השם ב-Site settings, למשל pshut-math.netlify.app).

איך מתקינים בטלפון:
• אנדרואיד (Chrome): נכנסים לכתובת → מופיע פס "התקנה" בתחתית → התקנה.
• אייפון (Safari): נכנסים לכתובת → כפתור שיתוף ⬆ → "הוספה למסך הבית".

מה מקבלים:
• אייקון על מסך הבית, נפתח במסך מלא בלי שורת כתובת.
• הסרטונים מתנגנים בתוך האפליקציה.
• התמונות הממוזערות נטענות ישירות מיוטיוב.
• עובד גם כשהאינטרנט חלש (הדף והתמונות נשמרים במטמון).

עדכון סרטונים: מחליפים את index.html וגוררים שוב את התיקייה לאותו אתר ב-Netlify (Deploys → גרירה).
אפשר גם להעלות ל-GitHub Pages או לכל אחסון אחר – העיקר שיהיה https.
